# Спецификация новых функций Excel 2026

Sep 30, 2026 · @George

## Обзор

Документ описывает списки, массивы в ячейках и вложенные массивы в Excel с четырьмя новыми функциями (`FLATTEN`, `HAS`, `HASANY`, `HASALL`) по анонсу Microsoft от 24 сентября 2026, а также шесть функций, которые я предлагаю дополнительно: заполнение пустых ячеек, скользящие окна, соединение таблиц, нечёткий поиск, разбор JSON и разбиение на интервалы.

Часть про списки, массивы и четыре функции основана на [анонсе Microsoft](https://techcommunity.microsoft.com/blog/Microsoft365InsiderBlog/put-multiple-values-in-one-cell-with-lists-and-arrays-in-excel/4559395); это предварительная версия в Beta Channel, поведение может измениться до общего выпуска. Функции `FILLDOWN`, `PARSEJSON`, `ROLLING`, `BINS`, `TABLEJOIN` и `FUZZYLOOKUP` — мои предложения, в анонсе их нет: их названия, синтаксис и сроки условны. Функции проектируются в стиле динамических массивов (`LET`, `LAMBDA`, `TEXTSPLIT`, `GROUPBY`).

**Аудитория:** аналитики, финансисты, авторы шаблонов, разработчики надстроек.

**Цели:**

- заменить многошаговые формулы и Power Query для типовых задач одной функцией;
- сохранить единый синтаксис: диапазоны и массивы на входе, разлив на выходе;
- не потерять обратную совместимость: в старых версиях функции показываются как `_xlfn.ИМЯ` с ошибкой `#ИМЯ?`.

## Сводка функций

Десять функций в четырёх категориях: подготовка данных, анализ, поиск и проверка вхождения.

| Функция | Категория | Назначение | Что заменяет |
| --- | --- | --- | --- |
| `FILLDOWN` | Подготовка данных | Заполняет пустые ячейки предыдущим непустым значением | Выделение пустых + `=ячейка выше` + вставка значений |
| `PARSEJSON` | Подготовка данных | Разбирает строку JSON в массив или значение по пути | Power Query и цепочки `MID`/`FIND` |
| `ROLLING` | Анализ | Применяет функцию к скользящему окну заданной ширины | `OFFSET` + `AVERAGE` в цикле из копированных формул |
| `BINS` | Анализ | Считает число значений в интервалах (гистограмма) | `FREQUENCY` с ручными границами |
| `TABLEJOIN` | Поиск и соединение | Соединяет две таблицы по ключу (inner, left, right, full) | Пары `XLOOKUP` по каждому столбцу |
| `FUZZYLOOKUP` | Поиск и соединение | Находит ближайшее по написанию значение в списке | Ручная чистка опечаток, надстройка Fuzzy Lookup |
| FLATTEN | Подготовка данных | Раскрывает вложенные массивы в один столбец | TOCOL в цикле и ручной разбор результатов MAP |
| HAS | Проверка вхождения | TRUE, если значение есть в списке | ISNUMBER(MATCH(...)) и COUNTIF(...)>0 |
| HASANY | Проверка вхождения | TRUE, если есть хотя бы одно из значений | OR(COUNTIF(...)) |
| HASALL | Проверка вхождения | TRUE, если есть все значения | AND(COUNTIF(...)) |

## Детальные спецификации

Каждая функция принимает диапазоны или массивы и возвращает разливающийся массив. Опциональные аргументы в квадратных скобках.

### Списки и массивы в ячейках

По анонсу Microsoft, в ячейке теперь может быть не одно значение, а список или массив.

- **Список.** Создаётся через Вставка > Список или Ctrl+J; элементы через запятую или точку с запятой (по региональным настройкам). Элементы меняются по двойному клику или F2. Фильтр работает по отдельным элементам. Ссылка `=B2` на ячейку со списком разливает все его значения по ячейкам.
- **Массив в ячейке.** Результат любой разливающейся формулы можно оставить в одной ячейке, обёрнув тело формулы в фигурные скобки `{ }`: массив оборачивается в массив 1×1 и не разливается. Скобки могут быть в несколько слоёв.
- **Вложенные массивы.** Например, `={{1,2,3};{4,5,6}}`. Раньше формула, возвращавшая массив массивов, давала усечённый результат или `#CALC!`; теперь возвращается полный вложенный результат. У `TEXTSPLIT` без вложенных массивов возвращается только первый элемент каждой строки, с ними — по одному массиву на строку.
- **Совместимость.** Для большинства расчётов с вложенными массивами нужна Compatibility Version 3 (Формулы > Параметры вычислений). Часть существующих формул в ней даёт другой результат; версии 1 и 2 можно оставить.

### FLATTEN

```
FLATTEN(array, [pad_value], [levels])
```

- `array` — массив, в том числе вложенный.
- `pad_value` — чем дополнить строки с меньшим числом элементов. В анонсе взята пустая строка `""`, чтобы оставшиеся столбцы были пустыми.
- `levels` — сколько уровней вложенности убрать (один или несколько).
- Возвращает упрощённый массив, который разливается по ячейкам.
- Пример из анонса: `FLATTEN` над вложенным результатом `TEXTSPLIT` с `pad_value` = `""`.

### HAS

```
HAS(array, value)
```

Возвращает `TRUE`, если `value` встречается в `array` где угодно, и `FALSE` в противном случае.

### HASANY

```
HASANY(array, values)
```

Возвращает `TRUE`, если в `array` встречается хотя бы одно значение из `values`, и `FALSE` в противном случае.

### HASALL

```
HASALL(array, values)
```

Возвращает `TRUE`, если в `array` встречаются все значения из `values`, и `FALSE` в противном случае.

В анонсе не указаны: значения по умолчанию у `pad_value` и `levels`, учёт регистра и подстановочные знаки в `HAS*`, поведение при пустом `values`, коды ошибок.

### Предложения автора

Функции ниже (`FILLDOWN` … `FUZZYLOOKUP`) не из анонса Microsoft, это проект автора документа.

### FILLDOWN

```
FILLDOWN(array, [direction], [skip_values])
```

- `array` — диапазон или массив с пустыми ячейками.
- `direction` — `1` (вниз, по умолчанию), `2` (вверх), `3` (вправо), `4` (влево).
- `skip_values` — массив значений, которые считаются пустыми (например, `""` и `"n/a"`).
- Возвращает массив той же размерности. Пустые ячейки до первого значения остаются пустыми.
- Ошибки: `#ЗНАЧ!`, если `direction` вне 1–4.
- Пример: `=FILLDOWN(A2:A10)` для столбца «Регион» с объединёнными группами строк.

### PARSEJSON

```
PARSEJSON(text, [path], [flatten])
```

- `text` — строка JSON.
- `path` — путь вида `$.orders[0].total`; без пути возвращается весь объект.
- `flatten` — `TRUE`: массив объектов разворачивается в таблицу с заголовками-ключами; по умолчанию `FALSE`.
- Возвращает скаляр (число, строка, логическое) или массив. `null` превращается в пустую ячейку.
- Ошибки: `#ЗНАЧ!` при невалидном JSON; `#Н/Д`, если путь не найден.
- Пример: `=PARSEJSON(B2, "$.customer.name")`.

### ROLLING

```
ROLLING(array, window, function, [min_periods])
```

- `array` — одномерный или двумерный массив (окно идёт по строкам).
- `window` — целое ≥ 1, размер окна.
- `function` — имя агрегата (`SUM`, `AVERAGE`, `MIN`, `MAX`, `MEDIAN`) или `LAMBDA` от одного аргумента.
- `min_periods` — минимум значений в окне; меньше — результат `#Н/Д`. По умолчанию равен `window`.
- Возвращает массив размера `array`.
- Ошибки: `#ЗНАЧ!` при `window` ≤ 0 или больше длины массива.
- Пример: `=ROLLING(C2:C31, 7, AVERAGE)` — 7-дневная скользящая средняя; первые шесть значений — `#Н/Д`.

### BINS

```
BINS(values, edges, [right_closed], [include_outside])
```

- `values` — числа для разбиения; `edges` — возрастающие границы интервалов, или одно целое число (количество равных интервалов).
- `right_closed` — `TRUE`: интервалы вида (a, b\]; по умолчанию `FALSE` — \[a, b).
- `include_outside` — `TRUE`: добавляет строки «меньше» и «больше».
- Возвращает таблицу из трёх столбцов: нижняя граница, верхняя граница, количество. Нечисловые значения и пустые ячейки пропускаются.
- Ошибки: `#ЗНАЧ!`, если `edges` не возрастают.
- Пример: `=BINS(D2:D500, {0,18,35,65})` — возрастные группы.

### TABLEJOIN

```
TABLEJOIN(left, right, left_key, right_key, [join_type], [suffix])
```

- `left`, `right` — таблицы с заголовками в первой строке.
- `left_key`, `right_key` — имя или номер столбца (или массив имён для составного ключа).
- `join_type` — `"inner"` (по умолчанию), `"left"`, `"right"`, `"full"`.
- `suffix` — суффикс для повторяющихся имён столбцов; по умолчанию `"_2"`.
- Возвращает таблицу: все столбцы `left` + столбцы `right` без ключа. Пропущенные совпадения дают пустые ячейки; порядок строк сохраняет `left`.
- Ошибки: `#Н/Д`, если ключ не найден в заголовке; `#ЗНАЧ!` при неизвестном `join_type`.
- Пример: `=TABLEJOIN(Orders, Customers, "customer_id", "id", "left")`.

### FUZZYLOOKUP

```
FUZZYLOOKUP(lookup_value, lookup_array, [return_array], [threshold], [if_not_found])
```

- `lookup_value` — текст (или массив текстов) для поиска; `lookup_array` — список эталонов.
- `return_array` — что вернуть; если опущен, возвращается найденный эталон.
- `threshold` — от 0 до 1 (схожесть по расстоянию Дамерау–Левенштейна, без учёта регистра); по умолчанию `0.8`.
- `if_not_found` — значение, если ничего не прошло порог.
- При ничьей выбирается первое совпадение в порядке списка.
- Ошибки: `#Н/Д` без `if_not_found`; `#ЗНАЧ!` при `threshold` вне \[0, 1\].
- Пример: `=FUZZYLOOKUP("Microsfot", A2:A100, B2:B100, 0.8)` находит «Microsoft».

## Нефункциональные требования

Целевые значения — предложения для обсуждения, не измеренные данные.

| Область | Требование |
| --- | --- |
| Производительность | `ROLLING`, `BINS`, `TABLEJOIN` на 1 млн строк считаются не дольше 2 с на стандартном ноутбуке; `TABLEJOIN` строит хэш-индекс, а не перебирает пары (O(n+m)). |
| Совместимость | Функции записываются в `.xlsx` с префиксом `_xlfn.`; в старых версиях остаётся кэшированное значение ячейки. |
| Локализация | Имена переводятся по языку интерфейса; разделитель аргументов берётся из региональных настроек. `PARSEJSON` всегда читает числа с точкой по стандарту JSON. |
| Безопасность | Ни одна функция не обращается к сети и файлам; `PARSEJSON` ограничивает глубину вложенности (64) и размер входа (32 767 символов — лимит ячейки). |
| Точность | Числа в формате IEEE 754 double, как в остальных функциях. |
| Доступность | Функции появляются в автодополнении и подсказках аргументов, озвучиваются скринридерами. |
| Compatibility Version 3 | Вложенные массивы в расчётах требуют Compatibility Version 3; часть существующих формул в ней даёт другой результат, поэтому версию 1 или 2 можно оставить. |
| Ограничения предварительной версии | Условное форматирование не смотрит внутрь массива без формулы; проверка данных не берёт список или массив как элементы выпадающего списка; диаграммы не разворачивают массив в точки; сводные таблицы не читают значения массивов; Power Query не загружает и не выдаёт столбцы-массивы; «Найти и заменить» не заменяет элементы списка или массива. |
| Доступность | Beta Channel: Windows версия 2610 (сборка 20520.20000) и новее, Mac версия 16.114 (сборка 26092111) и новее. Выпуск поэтапный, возможности могут быть приостановлены, изменены или убраны. |

## Критерии приёмки и тест-кейсы

Функция принята, если проходят все кейсы ниже и её разлив не ломается при вложении в `LET`, `LAMBDA`, `MAP` и `BYROW`.

| Функция | Вход | Ожидаемый результат |
| --- | --- | --- |
| `FILLDOWN` | `{"A";"";"";"B";""}` | `{"A";"A";"A";"B";"B"}` |
| `FILLDOWN` | `{"";"A"}` | `{"";"A"}` (начальные пустые остаются) |
| `PARSEJSON` | `'{"a":{"b":[1,2,3]}}'`, `"$.a.b[1]"` | `2` |
| `PARSEJSON` | `'{"a":'` | `#ЗНАЧ!` |
| `ROLLING` | `{1;2;3;4}`, `2`, `SUM` | `{#Н/Д;3;5;7}` |
| `ROLLING` | `{1;2;3}`, `5`, `SUM` | `#ЗНАЧ!` |
| `BINS` | `{1;5;9;10}`, `{0,5,10}` | `0 / 5 / 1` и `5 / 10 / 2 (10 вне полуоткрытого интервала)` |
| `BINS` | `{1;5;9;10}`, `{0,5,10}`, `TRUE` | `0 / 5 / 2` и `5 / 10 / 2` |
| `TABLEJOIN` | таблицы с дублирующимися ключами в `right` | по строке на каждое совпадение, порядок `left` сохранён |
| `FUZZYLOOKUP` | `"Microsfot"` в списке с «Microsoft», порог 0,8 | `"Microsoft"` |
| `FUZZYLOOKUP` | `"Apple"` в том же списке, без `if_not_found` | `#Н/Д` |
| FLATTEN | {{1,2,3};{4,5}}, pad\_value "" | две строки: 1,2,3 и 4,5,пусто |
| HAS | {"a";"b"}, "a" | TRUE |
| HASANY | {"a";"b"}, {"x","b"} | TRUE |
| HASALL | {"a";"b"}, {"a","x"} | FALSE |

## Открытые вопросы и выпуск

Релиз возможен только после решения вопросов ниже; сроки в этот черновик не входят, пока их не задаст владелец продукта.

- [ ] Алгоритм `FUZZYLOOKUP`: Дамерау–Левенштейн или Джаро–Винклер; что учитывать для кириллицы?
- [ ] `ROLLING`: нужны ли центрированные окна и окна по датам («7 дней» вместо «7 строк»)?
- [ ] Путь в `PARSEJSON`: полный JSONPath или подмножество (ключи и индексы)?

* [ ] `FLATTEN`: значения по умолчанию у `pad_value` и `levels`, в анонсе они не указаны.
* [ ] `HAS`, `HASANY`, `HASALL`: учёт регистра, подстановочные знаки и поведение при пустом `values` в анонсе не описаны.

**Предлагаемые шаги:**

1. Согласовать набор функций и имена.
2. Реализация и автотесты по таблице кейсов.
3. Закрытая бета для аналитиков и сбор отзывов.
4. Документация и переводы, затем выпуск.
